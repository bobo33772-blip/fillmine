# fillmine

모르는 사람과 한 롤을 채우는 필름 사진 앱. 같은 키워드로 모인 사람들이 한 컷씩 찍어 넣고, **10컷이 차면 함께 현상되어 모두에게 공개**된다.

지금은 디자인과 기능을 맞춰보는 **프로토타입** 단계다. 디자인과 기능이 확정되면 이 저장소에서 웹앱으로 만든다.

## 프로토타입 보기

**https://bobo33772-blip.github.io/fillmine/prototype/** (GitHub Pages)

GitHub 파일 화면에서는 HTML이 코드로만 보이므로 위 주소로 연다. `main` 브랜치에 올리면 1~2분 뒤 이 주소에도 반영된다.

내려받아 볼 때는 `prototype/index.html` 을 브라우저로 열면 된다. 파일 하나에 화면, 사진, 스크립트가 모두 들어 있다. 글꼴만 Google Fonts 에서 불러오므로 인터넷이 연결돼 있어야 한다.

## 규칙 (웹앱 기준, 2026-10-30)

웹앱은 노션의 팀 결정(2026-09-29)을 따르고, 탐색 게임 매칭만 뺀다. 자세한 내용과 근거는 [docs/decisions.md](docs/decisions.md) 에 있다.

- 다른 사람의 컷은 롤이 공개되기 전까지 가려져 있다.
- 반응은 순위와 숫자가 없는 **비공개 "마음에 든 사진"** 이다.
- 같은 롤에 **두 번 이상** 함께한 사람에게만 추천이 뜬다 → 찔러보기 → 서로 수락하면 대화.
- 사람은 얼굴 대신 **마크**(선 아이콘)로 보인다. 내 마크는 아이보리 원. 사진에도 얼굴은 넣지 않는다.
- 내 사진은 같은 롤 사람에게만 보인다. 올릴 때 위치정보(EXIF)는 자동으로 지운다.
- 만 19세 이상만 가입한다. 신고 · 차단이 있다.
- 하단 탭은 홈 · 필름메이트 · 내 필름.

아직 정하는 중인 것: 롤 크기와 공개 조건(10컷 vs 8명 · 24시간), 찔러보기 횟수, 댓글을 둘지 여부.

`prototype/index.html` 은 이 결정 전의 버전(10컷 공개, 공개 좋아요 · 댓글, 아무나 메이트 신청)이다.

## 디자인

어둡고 빈티지한 필름 무드. 팀이 고른 무드 사진이 배경으로 천천히 바뀌고, 주요 버튼은 오래된 종이 라벨, 보조 버튼은 이중선 테두리로 그린다.
글꼴은 Bodoni Moda (로고), Noto Serif KR (본문), IBM Plex Mono (숫자 · 라벨).
