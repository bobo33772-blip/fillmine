# 결정 기록

웹앱을 만들 때 기준이 되는 규칙과, 그 규칙이 언제 왜 정해졌는지 남긴다. 최신 결정이 위에 온다.

근거 문서는 노션 "필름릴레이" 페이지다. 특히 「04. 핵심 규칙 · 솔루션」의 팀 결정(2026-09-29)과 인터뷰 보완안(2026-10-02)을 본다.

---

## 2026-10-30 · 웹앱 규칙의 기준을 팀 결정으로

실제 웹앱으로 옮기기 전에 노션의 팀 결정과 프로토타입을 비교했고, 아래처럼 정했다.

### 팀 결정을 따른다

| 항목 | 규칙 | 프로토타입에서 바뀌는 점 |
|---|---|---|
| 반응 | 순위와 숫자가 없는 비공개 "마음에 든 사진". 찔러보기 추천의 근거로만 쓴다 | 공개 좋아요 수를 없앤다 |
| 연결 | 같은 롤에 **두 번 이상** 함께한 사람에게만 프로필과 찔러보기를 추천한다 → 찔러보기 → 서로 수락하면 대화 | 아무나 눌러 메이트 신청하던 흐름을 없앤다 |
| 연령 | 만 19세 이상만 가입 | 가입 흐름에 연령 확인을 넣는다 |
| 안전 | 신고 · 차단. 차단하면 롤 배정, 추천, 대화에서 모두 빠진다. 신고 사유에 "얼굴 · 개인 연락처 요구"를 따로 둔다 | 새로 넣는다 |
| 사진 | 올릴 때 위치정보(EXIF)를 자동으로 지우고, 지웠다고 알려 준다 | 새로 넣는다 |
| 공개 범위 | 내 사진은 같은 롤 사람에게만 보인다. 온보딩에서 먼저 알려 준다 | 공개 범위를 좁힌다 |

연령, 신고 · 차단은 팀 결정(09-29)이다. 위치정보 삭제, 공개 범위, "얼굴 · 개인 연락처 요구" 신고 사유는 인터뷰 보완안(10-02)이다.

**근거:** 모르는 사람에게 반응을 받은 19명 중 관계로 이어진 사람은 0명이었다(설문). 그래서 반응을 공개해 연결을 만드는 구조 대신, 같은 사람과 다시 마주치는 구조를 택한다. 인터뷰에서 이어진 관계에는 늘 반복 접점이 있었다.

### 팀 결정과 다르게 간다

- **탐색 게임 매칭은 넣지 않는다.** 팀 결정은 MVP 포함이었지만 웹앱에서는 제외한다. 연결은 롤에서 다시 마주치는 경로 하나로만 일어난다.

### 아직 정하지 않은 것

- **롤 크기와 공개 조건:** 프로토타입은 10컷이 차면 공개한다. 팀 결정은 8명이 1장씩, 8장이 차거나 24시간이 지나면 공개한다.
- **찔러보기 횟수:** 프로토타입은 한 사람에게 하루 1회다. 팀 결정은 하루 3회다.
- **댓글:** 프로토타입에는 공개 댓글이 있다. 팀 결정에는 댓글이 없고, 반응 수를 비공개로 한다는 원칙만 있다.

## 2026-10-18 · 프로토타입 v10: 10컷 공개와 소셜 기능

- 롤은 10컷이 차면 현상되어 공개된다.
- 공개된 롤에서 사진마다 올린 사람, 좋아요, 댓글을 보여 준다.
- 사람을 누르면 메이트 신청과 찌르기를 할 수 있다. 찌르기는 한 사람에게 하루 1회다.
- 같은 롤이 두 번 이상인 사람과 다시 만나면 알림을 보낸다.
- 하단 탭은 홈 · 필름메이트 · 내 필름, 메이트끼리 1:1 대화를 할 수 있다.

이 중 공개 좋아요와 "아무나 메이트 신청"은 10-30 결정으로 바뀐다.

## 2026-10-17 · 롤 크기를 24컷에서 10컷으로

24컷은 채우기까지 너무 길어서 10컷이 모이면 공개하기로 했다.
